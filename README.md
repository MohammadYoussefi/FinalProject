  <h1>🎓 Student Course Registration System</h1>
  <p>
    This project is a <strong>University Course Registration System</strong> built with <strong>FastAPI</strong>.  
    It was my university term project and helped me deeply understand how to design database relations and
    work with FastAPI features more effectively.
  </p>

  <div class="card">
    <h2>✨ Features</h2>
    <ul>
      <li>👨‍🎓 <strong>Student Management</strong> – Each student has attributes such as Student ID, term, address, faculty, and a list of enrolled courses.</li>
      <li>📚 <strong>Course Management</strong> – Each course contains details such as course ID, course name, assigned faculty, and the professor responsible.</li>
      <li>👨‍🏫 <strong>Professor Management</strong> – Professors have attributes like ID, national code, and a list of courses they teach.</li>
      <li>✅ <strong>Data Validation</strong> – Ensures the correctness of inputs and prevents invalid records.</li>
      <li>🔗 <strong>API Endpoints</strong> – Separate endpoints for Students, Courses, and Professors.</li>
      <li>🗄️ <strong>Database Integration</strong> – Well-structured relational database with optimized relations.</li>
    </ul>
  </div>
